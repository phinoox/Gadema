# ⚖️ Anima Lab: The Engine of Equilibrium

**Anima Lab** is a framework designed to bridge the gap between creative chaos and structural stability. It provides the architectural engine required to capture, stabilize, and manifest complex worlds.

---

## 🌌 The Core Concept: Equilibrium

Every creation exists in a state of tension between two extremes:
* **Creative Chaos**: The raw, unbridled rush of ideas that fuels the process but lacks structure.
* **Stagnation**: The heavy weight of rigid rules that can stifle creativity.

**Anima Lab provides the Equilibrium.** By implementing the **Soul & Body pattern**, we provide a stable identity (the Soul) while allowing for modular, evolving details (the Body). This ensures your world remains coherent even as it grows in complexity.

---

## 🏛️ The Laboratory: Our Development Environment

Our development environment, **The Laboratory**, is organized into specialized areas that mirror the layers of our architecture:

*   **The Core (`Gadema.Core`)**: The foundation where the **Soul & Body** patterns and **Harmonization** protocols are implemented.
*   **The Gateway (`Gadema.Api`)**: The communication layer that manages identity, permissions, and data flow.
*   **The Interface (`Gadema.WebApp`)**: The interactive environment where ideas are transformed into structured reality.

## 🛠️ Getting Started

### Prerequisites
* [.NET 10 SDK](https://dotnet.microsoft.com/download)
* [Docker](https://www.docker.com/) (for local database environment)

### Local Setup
```bash
# Clone the repository
git clone https://github.com/your-repo/anima-lab.git
cd anima-lab


# Initialize the database
dotnet ef database update --project src/Gadema.Data --startup-project src/Gadema.Api
```
